One-time publishing setup

The private Manage access workflow needs three repository Actions secrets before Accept & publish can complete:

  • TRAVEL_APP_PUBLISH_TOKEN: separate fine-grained token restricted to the public app repository, Contents read/write.
  • TRAVEL_SHARE_PASSWORD: your existing download password.
  • TRAVEL_SHARE_MASTER_KEY: random 32-byte key encoded as base64; keep it separate from all passwords and tokens.

Configure secrets in the private repository. Never paste secret values into request data or workflow inputs. The dashboard connection token needs Actions read/write and Contents read on the private repository.

No Cloudflare account or paid email service is needed. Existing offline plans stay available while setup is pending.
